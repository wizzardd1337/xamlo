# 😈 Роfl-бот «Дядя Жора»

Telegram-бот с нейронкой, который отвечает на `/talk` с подколами и сарказмом.

---

## Установка

### 1. Получи токен бота
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Напиши `/newbot` и следуй инструкциям
3. Скопируй **BOT_TOKEN**

### 2. Получи OpenAI API ключ
1. Зайди на [platform.openai.com](https://platform.openai.com/api-keys)
2. Создай новый ключ
3. Скопируй **OPENAI_KEY**

### 3. Вставь токены в `run.bat`
```bat
set BOT_TOKEN=1234567890:ABCDEFghijklmnopqrstuvwxyz
set OPENAI_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxx
```

### 4. Запусти бота
```
run.bat
```
или
```
python bot.py
```

---

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/help` | Справка |
| `/talk [текст]` | Получить ответ от нейронки |

### Пример:
```
/talk привет лох
```
Бот ответит чем-то вроде:
> "Привет, Дмитрий, слушай сюда: 'Привет лох' — это самое умное, что ты написал сегодня, и всё равно слабовато 💀"

## Правила бота (системный промпт)

**Запрещено:**
- ❌ Оскорбления семьи, мамы, папы, родственников
- ❌ Пожелания смерти/болезней
- ❌ Расизм, национализм, религиозные оскорбления

**Разрешено:**
- ✅ Стёб над самим человеком (слова, поступки, интеллект)
- ✅ Сарказм и острые шутки
- ✅ Лёгкие оскорбления без перехода черты

---

## Добавление в группу

1. Добавь бота в группу как участника
2. Дай ему права **отправлять сообщения**
3. Любой участник группы может писать `/talk [текст]`
